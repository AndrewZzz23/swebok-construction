02 · Ejemplo práctico en vivo

Prueba «Mis tareas»

Es la misma app de la presentación, compilada a web con flutter build web. El mismo código corre en Android, iOS y aquí, en el navegador.

Cómo usarla

  1. Escribe una tarea en el campo de texto.
  2. Pulsa el botón + o la tecla Enter.
  3. La tarea aparece en la lista: eso es setState redibujando la pantalla.

La primera carga puede tardar unos segundos mientras el navegador descarga el motor de Flutter.

03 · Código

Todo cabe en lib/main.dart

Un StatefulWidget guarda la lista; setState avisa a Flutter que la redibuje; build() describe la pantalla como un árbol de widgets.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Tareas()));

class Tareas extends StatefulWidget {
  const Tareas({super.key});
  @override
  State<Tareas> createState() => _TareasState();
}

class _TareasState extends State<Tareas> {
  final _items = <String>[];
  final _ctrl = TextEditingController();

  void _agregar() {
    if (_ctrl.text.trim().isEmpty) return;
    setState(() => _items.add(_ctrl.text.trim()));
    _ctrl.clear();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Mis tareas')),
      body: Column(children: [
        TextField(controller: _ctrl, onSubmitted: (_) => _agregar()),
        Expanded(
          child: ListView.builder(
            itemCount: _items.length,
            itemBuilder: (_, i) => ListTile(title: Text(_items[i])),
          ),
        ),
      ]),
      floatingActionButton: FloatingActionButton(
        onPressed: _agregar, child: const Icon(Icons.add)),
    );
  }
}
